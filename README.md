# Assessment workflow demo

A public South Pacific albacore example of the KIMSA model-to-report workflow.
The results come from KIMSA refits of the 2024 diagnostic and ensemble inputs and
include model development, starting-value trials, simulation-estimation tests,
retrospectives, index hindcasts, a likelihood profile and stochastic projections.
This remains a workflow demonstration rather than an updated official assessment.

- [Read the report](https://kyuhank.github.io/assessment-workflow-demo/)
- [Download the PDF](https://kyuhank.github.io/assessment-workflow-demo/main.pdf)
- [Explore the diagnostic results](https://kyuhank.github.io/assessment-workflow-demo/artifacts/diagnostic/comparison.html)
- [Explore model development](https://kyuhank.github.io/assessment-workflow-demo/artifacts/stepwise/comparison.html)
- [Explore ensemble results](https://kyuhank.github.io/assessment-workflow-demo/artifacts/ensemble/comparison.html)

This repository publishes rendered reports, figures, tables and interactive pages.
KIMSA package source, editable report source, serialized model objects and private
workflow inputs are maintained separately and are not included in the site.
