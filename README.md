# Assessment workflow demo

An ALB example of the model-to-report workflow. This is a workflow demonstration,
not a stock assessment. The diagnostic figures use an archived fitted model;
additional studies use illustrative values.

- [Read the report](https://kyuhank.github.io/assessment-workflow-demo/)
- [Download the PDF](https://kyuhank.github.io/assessment-workflow-demo/main.pdf)
- [Explore the diagnostic results](https://kyuhank.github.io/assessment-workflow-demo/artifacts/diagnostic/comparison.html)
- [Browse figures and tables](https://kyuhank.github.io/assessment-workflow-demo/artifacts/diagnostic/report.html)

This public repository contains rendered reports, figures, tables and interactive
pages. Development packages and editable workflow sources are maintained separately.
